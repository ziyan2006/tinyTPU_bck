01 / ISA · 80 BITS

一条指令，告诉硬件算什么、从哪读、往哪写

每条指令为 10 字节。普通计算格式如下，操作码位于最低 8 位；加载权重时，两个地址字段合并为 40 位权重地址。

上图按位编号从高到低排列；C 端通过 lower_word、middle_word、upper_word 三次写入组装指令。

操作编码实际行为
空操作0x00不启动计算单元
加载权重0x08 / 0x09无符号 / 有符号；权重缓冲 → MMU 预装寄存器
矩阵乘法0x20 / 0x21 / 0x22 / 0x23bit0：有符号输入；bit1：累加而非覆盖
激活0x80 系列bit4：有符号；低 4 位：0 取高字节 [31:24]、1 ReLU、9 Sigmoid
同步0xFF等待各单元资源忙结束，产生 SYNCHRONIZE
停止（文档）0x02当前 CONTROL_COORDINATOR 无专门译码，落入空操作分支

译码优先级：0xFF → bit7 激活 → bit5 矩阵乘法 → bit3 加载权重 → 空操作。文档的 Sigmoid 编码例子与实际低 4 位枚举不一致；当前有符号 Sigmoid 是 0x99（153）。RELU6、TANH 等虽在枚举中，激活模块未实现。

主机写入输入 / 权重→read_weights→matrix_multiply→activate→synchronize→主机读取输出

主机经 AXI 内存映射搬运数据，没有 DMA_LOAD、CONV2D、UPSAMPLE2X 等专用指令。length 表示向量处理长度，不是传输字节数。分块矩阵先覆盖累加器，再逐块累加，最后激活。

TRY IT / 指令编码器

地址字段范围是编码范围，不等于实际存储容量。AXI 顶层默认权重深度 32768、统一缓冲深度 4096；需按硬件配置检查寻址范围。
